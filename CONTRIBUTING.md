# Contributing to Taskyy

Use [Discussions](https://github.com/aronyok-io/Taskyy/discussions) for questions, feature ideas, and theme sharing. Open an [issue](https://github.com/aronyok-io/Taskyy/issues/new/choose) for a reproducible bug.

On Fedora, install `cargo`, `gcc`, `pkgconf-pkg-config`, and `fontconfig-devel`. Run `cargo test --locked` and `cargo run --locked` from the checkout. See the [README](README.md) for packaging and desktop smoke tests.

Keep pull requests focused. Describe the behavior you changed and how you tested it. For UI changes, check light and dark mode and include screenshots with sample data or redact personal information. Never attach full process lists, command lines, or logs containing credentials.
